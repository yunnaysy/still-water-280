A short text that settles a reader by setting the pace of reading beside the pace of a mountain reading a valley: one word, one frost, one thaw, one flake of stone, a million years passing, and a valley still there before the mountain reaches the end. It is written to be read without hurry, and to leave a scale that keeps growing after the last line. To run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`, which writes `out/entry.txt`; `node tools/check.mjs` reruns it and asserts valid UTF-8, a 1-280 code-point length, and text that is not only whitespace.
